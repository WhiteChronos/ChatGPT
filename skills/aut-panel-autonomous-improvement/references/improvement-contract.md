# Improvement Contract

Every proposal should record:
- proposal_id
- trigger/evidence
- root cause
- affected artifacts
- severity/frequency
- proposed change
- expected benefit
- implementation risk
- rollback plan
- regression test
- sandbox result
- human gate status
- applied version
- post-change metric

Default lifecycle:
`PROPOSED -> SANDBOXED -> QA_PASSED -> HUMAN_APPROVED -> APPLIED -> MEASURED`

Rejected proposals remain in history with rationale.
