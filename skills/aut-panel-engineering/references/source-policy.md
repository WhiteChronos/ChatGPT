# Source policy

For every source record capture reference ID, equipment, manufacturer, model/family, document type/title/code/revision/date/language, official page and direct file links when available, consultation date, lifecycle status, project application, exact page/figure/table/section, limitations/divergences, Validator A result, Validator B result, and reverification timestamp.

Do not mark a component approved for issue until manufacturer/model, official document, link, page/section, consultation date, product status, official supplier/channel, independent dual validation, and reverification are present.
