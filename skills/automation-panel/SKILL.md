# Identificar quadro de automação

## Procedimento

- Registrar exatamente as TAGs mostradas.
- Usar o quadro como referência de origem.
- Não inferir relações entre TAGs sem evidência.

## Persistência
- Registrar resultado, fontes, pendências e próximo passo no checkpoint.
- Preservar terminologia do desenho e não preencher lacunas com suposições.
