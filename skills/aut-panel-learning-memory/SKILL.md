# AUT Panel Learning & Memory

Preserve useful learning without contaminating engineering authority.

## Workflow
1. Record user decisions as panel-scoped canonical premises.
2. Record validated external findings with source metadata in the Data Center.
3. Record confirmed errors with root cause, affected artifacts, preventive rule and regression test.
4. Keep history append-only for released revisions.
5. Store reusable methodology separately from panel-specific facts.
6. Generate improvement proposals from repeated failures or inefficiencies.
7. Simulate/test proposals before human approval.
8. ML, memory plugins and knowledge stores are advisory; deterministic gates and official sources remain authoritative.

## Plugin usage
- Airtable/Coda/Notion: structured indexes, issue registers and knowledge capture.
- Tavily/Firecrawl: source discovery/crawl.
- Scite: academic evidence.
- Wolfram: calculations.
- Acumen: detect potentially missing current context; validate all surfaced facts independently.

Never promote an unverified plugin result directly into a released engineering fact.
