# Step 4 Toolchain

## Engineering-authoritative or deterministic support
- Manufacturer CAD/dimensional drawings: primary component geometry.
- QElectroTech: open-source electrical schematic/wiring authoring candidate, GPL-2.0-or-later.
- QetWireManager: QElectroTech wire-management support candidate, MIT repository.
- WireViz: wire/harness description and visualization candidate, GPL-3.0.
- FreeCAD/OpenCascade/CadQuery/build123d: deterministic geometry and measured routing.
- NetworkX: connection graph completeness/topology.
- OR-Tools: optional routing/placement optimization.
- Wolfram: independent length/area/volume/fill/load checks.

Open-source tools require pin, license/security review, sandbox/regression test and human approval before core production promotion.

## ChatGPT plugins/connectors
- Remote Desktop Commander: operate authorized local engineering applications when installed and connected.
- B&A Diagrams, tldraw, Miro: architecture/review diagrams only.
- Tavily/Firecrawl: manufacturer/supplier/manual discovery.
- Scite/Consensus: academic support.
- Engram/Airtable/Coda/Notion: supplemental memory/indexing.

No current ChatGPT plugin in the directory is treated as a dedicated replacement for EPLAN/AutoCAD Electrical/QElectroTech-style engineering.
