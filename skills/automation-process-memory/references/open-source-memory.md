# Open-source memory backends

Primary audit trail: GitHub history.

Secondary candidates already forked by the user:
- Mem0: upstream `mem0ai/mem0`, fork `WhiteChronos/mem0`, Apache-2.0.
- Graphiti: fork `WhiteChronos/graphiti`, real-time/temporal knowledge graph use case.
- Cognee: upstream `topoteretes/cognee`, fork `WhiteChronos/cognee`, Apache-2.0.
- Hindsight: upstream `vectorize-io/hindsight`, fork `WhiteChronos/hindsight`, MIT.
- Letta, OpenMemory and memU: optional comparative backends; verify current license and deployment requirements before production use.

Selection criteria: deterministic export, provenance retention, self-hosting, deletion controls, schema control, retrieval quality, temporal relationships, operational complexity and vendor independence.
