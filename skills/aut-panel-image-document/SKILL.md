# AUT Panel Image Document

Load MODEL 001 plus PROMPT_DIRETRIZ_ELABORACAO_IMAGEM_PN_V1 before any visual work.

## Workflow
1. Verify target panel Data Sheet, LI/BOM, layout and geometry are current.
2. Use MODEL 001 only for visual/document structure.
3. Render front external, front internal/open door, and lateral 3/4 from the same assembly.
4. Lateral 3/4 dimension must show only the target enclosure real depth on the real depth axis.
5. Include electrical architecture, communication architecture, command diagram, panel sizing, legend and panel data.
6. Do not show large manufacturer footer logos.
7. Do not invent protocols, equipment, tags, dimensions or quantities.
8. Grow canvas; never squeeze geometry.
9. Verify LI = BOM = LOAD = DATASHEET = LAYOUT = GEOMETRY = IMAGE.
10. Sync Data Center and memory after an approved visual revision.
