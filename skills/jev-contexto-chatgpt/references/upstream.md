# Jev — fonte e limite de integracao

Origem: https://github.com/tamaratran/fast-jev-compaction
Biblioteca TypeScript/JavaScript `fast-jev-compaction`, licenca MIT na versao analisada.
Funcoes citadas no upstream: `collectToolCalls`, `fitState`, `batchCalls`, `decideCall`, `applyDecisions`.
A biblioteca requer transcript acessivel, transporte para Jev e hooks/controle de invocacao. A interface do ChatGPT Web nao oferece esses hooks para skills comuns.
Uma skill ChatGPT pode definir estrategia de uso do contexto visivel, mas nao instalar internamente o algoritmo upstream.
