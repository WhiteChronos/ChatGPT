# Reference Stack for Realistic Panel Representation

Priority:
1. target-project documents, frozen LI/load and Data Sheet;
2. manufacturer CAD and dimensional drawings;
3. manufacturer enclosure/component assembly manuals;
4. manufacturer control-cabinet mounting/wiring process references;
5. applicable standards and Step 3 evidence;
6. recognized academic/technical references;
7. official training/assembly videos;
8. secondary videos only as procedural support.

Open-source stack: FreeCAD/FreeCAD, CadQuery/cadquery, gumyr/build123d, Open-Cascade-SAS/OCCT, mikedh/trimesh, isl-org/Open3D, blender/blender, opencv/opencv, JohannesBuchner/imagehash, mozman/ezdxf.

All open-source dependencies require pinning, license/security review, sandbox and regression validation before production promotion.
