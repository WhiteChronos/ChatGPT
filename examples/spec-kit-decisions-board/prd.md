# PRD — Example: Project Decisions Board

## Problem
Engineering project decisions become difficult to find across work sessions.

## Audience
Project engineer reviewing an authorized internal sample.

## MVP requirements
- REQ-01: Capture a decision with ID, title, rationale and date.
- REQ-02: List captured decisions in chronological order.
- REQ-03: Export decisions as Markdown without credentials.

## Out of scope
Authentication, cloud deployment, notifications, live database and automatic GitHub writes.

## Acceptance
AC-01 maps to REQ-01; AC-02 maps to REQ-02; AC-03 maps to REQ-03. All acceptance scenarios use synthetic data.
