# Regra de Ouro - Governance

## Princípios Fundamentais

Este documento estabelece as regras fundamentais para a governança do projeto.

### 1. Qualidade de Código
- Todo código deve passar na validação de CI/CD
- Testes unitários são obrigatórios
- Documentação deve ser mantida atualizada

### 2. Controle de Versão
- Commits devem ser atômicos e bem descritos
- Branches devem seguir nomenclatura padrão
- Pull Requests requerem review antes de merge

### 3. Segurança
- Credenciais nunca devem ser commitadas
- Dependências devem ser auditadas regularmente
- Conformidade com políticas de segurança é obrigatória
