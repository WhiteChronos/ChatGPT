# Datasheet Contract

Every project evaluation datasheet must carry:

- project identity;
- reconciled baseline;
- document inventory and SHA-256 provenance;
- reference context/profile;
- assessment records;
- Protocol Zero questions;
- structured Automation Hyperfocus checks;
- complete findings;
- scope summary;
- coverage;
- compatibility global/by discipline/by document/interface;
- blocking missing documents;
- release gate;
- visualization contract.

Until standalone extraction is complete, the canonical machine schema is `/schemas/engineering_compatibility.schema.json`.
