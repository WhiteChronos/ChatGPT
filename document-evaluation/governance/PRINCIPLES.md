# Product Principles

1. Evidence before inference.
2. Question before finding.
3. Preserve the master discipline for physical attributes.
4. Separate project facts from external engineering requirements.
5. Open source supports engineering; it does not define the project.
6. Fail closed when evidence is insufficient for release.
7. Keep coverage distinct from compatibility.
8. Make every metric reproducible.
9. Keep raw evidence immutable.
10. Keep human approval outside agent self-authorization.
11. Prefer complete technical visualization over opaque summaries.
12. Design every contract for machine validation and later agent execution.
