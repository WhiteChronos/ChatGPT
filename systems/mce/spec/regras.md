# Regras MCE

Preservar original, hashes, cabeçalho, macros, fórmulas, estilos e mesclas. No máximo 50 causas/folha. Não inventar dados de instrumentação nem lógica de intertravamento. Aprovação humana documental obrigatória. Não conectar a motores de engenharia reversa para autorizar mudanças no Excel.
