# Instalar MCE no ChatGPT Web

As duas pastas em `.agents/skills` sao uma estrutura de uso em repositorio/Codex; publicar no GitHub **nao registra** automaticamente Skills na conta ChatGPT. Para adicionar ao ChatGPT Web, importe individualmente `skill.zip` de cada Skill na biblioteca de Skills, se a sua interface oferecer esse recurso. Nao existe MCP obrigatorio no MCE.

A disponibilidade em uma conversa deve ser confirmada por descoberta real das Skills. Nao publicar planilhas mestres nem anexos de engenharia no GitHub.
