# Checklist Operacional

## Descoberta
- [ ] TAG/família/função identificados
- [ ] fabricante confirmado
- [ ] modelo/part number confirmado
- [ ] dois discriminadores técnicos compatíveis
- [ ] catálogo oficial localizado
- [ ] ficha técnica PDF localizada
- [ ] desenho dimensional localizado
- [ ] CAD/BIM pesquisado
- [ ] fornecedores classificados

## Elaboração
- [ ] fonte classificada
- [ ] unidade de origem confirmada
- [ ] geometria preservada/reconstruída
- [ ] fixações incluídas
- [ ] conexões incluídas
- [ ] vistas incluídas
- [ ] 1:1
- [ ] metros
- [ ] Arial
- [ ] layers normalizados

## QA
- [ ] identidade validada
- [ ] extents validados
- [ ] dimensões comparadas
- [ ] interfaces verificadas
- [ ] auditoria DXF sem erro crítico
- [ ] comparação visual concluída
- [ ] conflitos registrados
- [ ] manifesto completo

## Melhoria
- [ ] defeito capturado
- [ ] causa raiz registrada
- [ ] melhoria proposta
- [ ] regressão executada
- [ ] gate humano realizado quando aplicável
- [ ] memória atualizada
