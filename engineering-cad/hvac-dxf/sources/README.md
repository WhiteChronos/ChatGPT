# Proveniencia de fabricante

Para cada equipamento criar uma entrada com:
- fabricante
- modelo / part number
- pagina oficial do produto
- catalogo oficial
- ficha tecnica
- desenho dimensional
- CAD/BIM nativo
- numero do desenho e revisao
- dimensoes e ordem dimensional
- classe: CAD_FABRICANTE / RECONSTRUCAO_FICHA / REFERENCIA_PROJETO
- conflito com documentos do projeto, se houver

Nao usar marketplace, imagem comercial ou desenho sem procedencia como fonte dimensional primaria.
