# Technical Object Schema

Identity: project_tag, discipline, equipment_family, function, manufacturer, manufacturer_region, series, exact_model, part_number, revision_or_variant, lifecycle_status.

Technical discriminators as applicable: width/height/depth, diameter, mass, mounting orientation/hole pattern, flange/duct/pipe geometry, refrigerant/liquid/gas/drain sizes, electrical entries, voltage/phase/frequency, capacity, airflow, pressure, IP/NEMA, service clearance.

Provenance: product page, catalog, datasheet PDF, installation manual, dimensional drawing, drawing number/revision, native CAD URL/format, suppliers, checked date.

Confidence: HIGH, MEDIUM, LOW, BLOCKED.
Source class: CAD_FABRICANTE, RECONSTRUCAO_FICHA, REFERENCIA_PROJETO, BLOQUEADO.
