# ECC capability catalog

Observed upstream at ECC 2.2.3 contains 293 canonical Skills. Load the current upstream Skill when a concrete task matches rather than treating this list as behavioral instructions.

Major capability families include:

- **Core engineering:** coding standards, TDD workflow, verification loop, error handling, contract-first development, architecture decision records, git workflow.
- **Security:** security review, security scan, AgentShield-oriented workflows, application/framework security patterns, supply-chain and guardrail workflows.
- **Languages/frameworks:** Python, TypeScript/JavaScript, React, Vue, Angular, Go, Rust, Java/Spring, Kotlin, Swift, C/C++, C#/.NET, PHP/Laravel, Django, FastAPI, Rails, Flutter/Dart and others.
- **Agent systems:** agentic engineering, agent architecture audit, harness construction, autonomous loops, team orchestration, evaluation, operator approval loops, multi-model councils.
- **MCP/integrations:** MCP server patterns, API connector builder, GitHub ops, Jira integration, workspace and external-service operations.
- **Testing/quality:** E2E, language-specific testing, regression/eval harnesses, production audits, performance and benchmark workflows.
- **Infrastructure/platform:** Docker, Kubernetes, deployment patterns, networking, homelab, database and data-platform patterns.
- **Product/UI/content:** accessibility, frontend design direction, design systems, dashboards, SEO, presentations/slides, video/content workflows.
- **Research/knowledge:** deep research, documentation lookup, codebase onboarding, knowledge operations, literature/scientific workflows.

Use upstream descriptions and repository-local policy to choose the exact Skill.
