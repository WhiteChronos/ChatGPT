# Routing order

For high-impact software-development work in WhiteChronos:

1. System/developer/user/repository constraints.
2. Superpowers for the main development process and its mandatory gates.
3. ECC for specialized domain, framework, security, agent-harness, verification, or operational capability.
4. Matt Pocock for specialized workflows where it is more specific or explicitly requested.
5. GitHub connector for repository evidence and mutations.
6. GitHub Arena for final adversarial review.

Avoid duplicating TDD, debugging, planning, and generic code-review workflows across all three libraries. Add specialized passes only when they contribute distinct evidence.
