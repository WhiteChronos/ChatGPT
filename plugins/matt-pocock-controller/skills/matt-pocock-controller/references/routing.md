# Routing with Superpowers, Matt Pocock, and Arena

## Default order

For high-impact development work:

1. Repository/system/user constraints.
2. Official Superpowers process skill.
3. Matt Pocock specialized skill when useful and invocation policy allows.
4. GitHub connector for repository evidence and mutations.
5. Verification.
6. GitHub Arena adversarial review.
7. PR/merge workflow.

## Examples

- New feature: Superpowers `brainstorming` → implementation workflow; optionally Matt `domain-modeling` or `codebase-design` for a specialized seam/domain pass.
- Bug: Superpowers `systematic-debugging`; use Matt `diagnosing-bugs` only when explicitly requested or when repository policy selects it.
- Research: Matt `research` when a cited primary-source research artifact belongs in the repo.
- Manual infrastructure setup: Matt `wizard`.
- PR narrative: Matt `pr`, after implementation evidence exists.
- Agent-facing docs: Matt `writing-for-agents`.

Never silently invoke a Matt user-invoked skill.
