# Stable skill catalog

Observed from `mattpocock/skills` at version 1.2.3.

## Engineering — user-invoked

These require explicit user invocation:

- `ask-matt` — router over user-invoked Matt workflows.
- `grill-with-docs` — requirements grilling plus glossary/ADR domain docs.
- `triage` — issue triage state machine.
- `improve-codebase-architecture` — survey deepening opportunities and present a visual report.
- `setup-matt-pocock-skills` — configure issue tracker, triage labels, and domain-doc layout.
- `to-spec` — turn the current conversation into a spec and publish it.
- `to-tickets` — break a plan/spec/conversation into tracer-bullet tickets.
- `implement` — implement one work unit using TDD and review.
- `implement-spec` — implement a whole spec as a task graph.
- `wayfinder` — plan very large work across multiple sessions.
- `retro` — recommend improvements to the agent engineering environment.

## Engineering — model-invoked

These may be selected automatically when their descriptions match:

- `prototype` — throwaway prototype to answer a design question.
- `diagnosing-bugs` — disciplined bug/performance diagnosis.
- `research` — primary-source research captured as cited Markdown.
- `tdd` — red-green-refactor vertical slices.
- `domain-modeling` — actively sharpen the project domain model.
- `codebase-design` — deep-module/code seam design discipline.
- `code-review` — standards + spec review.
- `pr` — PR summary, evidence, and merge-danger framing.
- `wizard` — interactive bash wizard for human-only setup/cutover steps.
