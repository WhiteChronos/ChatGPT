# Awesome LLM Apps Controller

WhiteChronos control-plane integration for `Shubhamsaboo/awesome-llm-apps`.
It keeps the upstream mirror read-only, projects only registry-approved canonical Skills, indexes all qualifying agent/app components, and gates execution according to risk class.

The generated catalog lives at `registry/awesome-llm-apps/catalog.json`. The upstream provenance lock lives at `plugins/awesome-llm-apps-controller/upstream.lock.json`.
